# 🪙 CoinTrack.io

> **Local & Private Coin Collection Manager**

**CoinTrack.io** is a lightweight, privacy-first web application for managing and inventorying coin collections. It runs 100% locally in your web browser—requiring zero installation, no backend databases, no server infrastructure, and no monthly fees.

---

## ✨ Features

- 🔒 **100% Private & Local:** All coin data and photos stay securely in your browser's local storage.
- 📸 **Paste-Ready Photos:** Easily paste images directly from your clipboard (`Ctrl+V` / `Cmd+V`) or pick files from your device.
- 🪙 **Front & Back Image Support:** Upload high-resolution obverse and reverse photos for each item in your collection.
- 📊 **Live Stats & Search:** Automatically calculates total coin counts and estimated collection value with real-time text filtering.
- 💾 **JSON Backup & Import:** Export your entire collection (data + images) into a single `.json` file for safe-keeping or moving between browsers.
- 🖨️ **Print-Friendly CSS:** Built-in print stylesheets clean up the layout so you can easily print or save PDF collection ledgers.

---

## 🚀 Quick Start

### Running Locally
1. Download or clone this repository.
2. Double-click `index.html` to open it in any web browser (Chrome, Safari, Firefox, Edge).

### Deployment
This project is built as a single static web application. It can be hosted for free on platforms like **GitHub Pages**, **Cloudflare Pages**, **Vercel**, or **Netlify**.

---

## 🛠️ Built With

- **HTML5** (Semantic layout & Structured Data Schema)
- **CSS3** (Responsive CSS grid, variables, and `@media print` styling)
- **JavaScript (ES6)** (Native `localStorage`, Canvas API image compression, and Clipboard event handlers)
